# Last Text at One Percent

Program ini menulis satu pesan terakhir dari ponsel yang tersisa 1% baterai ke `/output/entry.txt`.

## Menjalankan

```bash
python3 main.py
```

Pesan dibatasi maksimal 200 karakter dan ditulis sebagai UTF-8.
